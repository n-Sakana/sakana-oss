# Table Record Editor

Excel の ListObject テーブルを、上下分割のフォームで閲覧・編集する VBA UserForm 一式です。

## 構成

- 上エリア
  - 左側: テーブル列から自動生成する 1 行入力フォーム
  - 右側: 末尾の表示対象列を使う詳細入力フォーム
- 下エリア
  - テーブルのレコード一覧
  - 選択したレコードを上エリアへ表示
- 上下エリアはスプリッターで高さを変更できます。
- フォーム右下のハンドルでフォーム全体のサイズを変更できます。
- Excel の列幅、表示形式、配置をもとに、入力欄と一覧の幅・配置・表示値を調整します。

## ファイル

- `src/TableRecordEditor.bas` — 起動用標準モジュール
- `src/frmTableRecordEditor.frm` — 動的 UI を組み立てる UserForm
- `src/TableRecordEditorField.cls` — 動的 TextBox のイベント連携クラス

## 使い方

1. VBA エディターで対象ブックまたは `.xlam` プロジェクトを開きます。
2. `src` 配下の 3 ファイルをインポートします。
3. Excel テーブル内のセルを選択します。
4. `OpenActiveTableRecordEditor` を実行します。

テーブル名を指定して開く場合は次を実行します。

```vb
OpenNamedTableRecordEditor "Table1"
```

## 動作仕様

- 表示対象は、非表示列を除いた ListObject の列です。
- 末尾の表示対象列を詳細欄として扱います。
- それ以外の列は、左側の 1 行入力フォームへ縦に並べます。
- 左側フォームが上エリア内に収まらない場合は縦スクロールします。
- 下の一覧で行を選ぶと、上のフォームに同じ行の値を表示します。
- 入力欄を編集すると、選択中のテーブル行へ即時に書き戻します。
- 数値、通貨、日付らしい表示形式は、表示時の整形と入力時の型変換を試みます。
- 標準の UserForm 内だけでサイズ変更を行い、WinAPI は使いません。

## 注意

- 編集内容は元の Excel テーブルへ直接反映されます。
- 既存データに適用する前に、コピーしたブックで確認してください。
- 保護シートや読み取り専用ブックでは書き戻しに失敗します。
